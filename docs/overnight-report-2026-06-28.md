## 🔴 Найденные узкие места (честно)

1. **Zapier для FB-лидов — платный** (FB Lead Ads + Webhooks = premium, ~$20+/мес).
   → Бесплатно: **Make.com** (1000 операций) в наш вебхук, или **CSV из Meta** руками
   на старте при малом потоке. Наш вебхук принимает POST от любого бриджа.
2. **End-to-end НЕ протестирован вживую** (webhook→…→запись в Sheet с кредом): полный
   прогон записал бы строку в живую «Leads» и дёрнул lead-helper. Делаем **завтра,
   контролируемо, с твоим тестовым телефоном** (`TEST Kirill`).
3. **Make free + FB Lead Ads** — не подтвердил на 100%, что триггер доступен на free.
   Проверим при настройке; если нет — Pabbly или платный Zapier.
4. **Нормализация пропускает «длинный мусор»** (9+ цифр уходит как есть) — но это
   поведение идентично текущим website/Meta веткам (не регресс), и дедуп консистентен.
5. **Анализ конкурентов**: официальный Instagram API контента конкурентов НЕ даёт —
   только Metricool (лицензир.) или ручной ввод. Учтено в metricool-setup.md.

## Фаза 2 — авто-контент-бот через Metricool (дизайн + прототип)

По второму правилу (free + автомат, без вопросов) подготовил основу бота, который сам
исследует рынок, готовит посты/сторис и публикует через Metricool:

- **Дизайн** `docs/auto-content-bot-design.md` — автономный цикл (research → plan →
  create → safety → schedule → learn), решения выбраны под free+автомат.
- ✅ **Прототип сторис-картинки 1080×1920** на твоём бренд-движке — отрендерён и
  **проверен глазами** (`docs/samples/story-sample-1080x1920.png`). Доказывает, что
  сторис-формат генерится автоматически (у тебя был только квадрат 1080×1080).
- 🔴 **Честные факты:** интерактивные сторис (опросы/стикеры) IG не даёт авто-публиковать
  → делаем простые; лимит 50/сутки; авто-постинг снимает текущую границу «только
  черновики» (`content-bot/index.js:9`).
- 🛡️ **Авто-гейт безопасности** вместо ручного ревью: для детского центра подпись
  всегда через child-safe `CAPTION_SYSTEM` + Claude само-проверяет против инварианта
  C.4 перед публикацией. Без ручного шага, но бренд/дети защищены.
