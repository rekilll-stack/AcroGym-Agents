# Авто-контент-бот через Metricool — дизайн (free + автомат)

Цель: бот, который **сам** изучает рынок, готовит брендовые картинки (посты + сторис),
пишет тексты и **автоматически публикует** в Instagram через Metricool. Всё бесплатно
и без ручной работы (правило Кирилла: всегда free + автомат, не спрашивать).

> Статус: **дизайн + проверенный прототип сторис-картинки**. Живая интеграция —
> после подключения Metricool (за Кириллом, OAuth). Полная сборка большая и снимает
> текущую границу content-bot (`index.js:9` — «только черновики, публикации НЕТ
> намеренно»), поэтому требует осознанного включения. См. [[acrogym-lead-bridge-prep]].

---

## Решения (выбрано под free + автомат, без вопросов)

| Слой | Чем делаем | Цена |
|---|---|---|
| Исследование рынка | Metricool MCP: анализ конкурентов + своя аналитика/лучшее время | free |
| Идеи / тексты / заголовки | Claude **Opus** (уже есть `generate.js`) | в твоём тарифе |
| Картинки постов 1080×1080 | `composeBrandedImage()` (уже есть) | free |
| **Картинки сторис 1080×1920** | **НОВОЕ** `composeBrandedStory()` — прототип готов и проверен (`docs/samples/`) | free |
| Публикация постов/reels/простых сторис | Metricool MCP (авто-публикация) | free |
| Оркестрация (цикл) | новый планировщик (PM2/cron) | free |

---

## Автономный цикл

```
1. RESEARCH (раз в неделю)  Metricool → темы/форматы конкурентов + твоё «что зашло» и лучшее время
2. PLAN                     Opus → контент-календарь (тема, формат, пост/сторис, дата/время)
3. CREATE (на каждый пункт) фон зала → composeBrandedImage / composeBrandedStory + текст (Opus)
4. SAFETY GATE (автомат)    авто-проверка по детской-безопасности (см. ниже) — НЕ ручная
5. SCHEDULE                 Metricool MCP ставит в график на лучшее время → авто-публикация
6. LEARN                    Metricool отдаёт метрики → следующий цикл умнее
```

## 🔴 Честные ограничения (факты, не вопросы)

1. **Интерактивные сторис** (опросы, стикеры, link-стикеры) Instagram **не даёт
   авто-публиковать** — только через уведомление вручную. → Для полного автомата
   делаем **простые картинка/видео сторис** (как прототип). Это решение, а не вопрос.
2. **Лимит Instagram API: 50 публикаций / 24 ч** (посты+reels+сторис вместе).
3. **Снятие границы «только черновики».** Сейчас в content-bot кода публикации нет
   намеренно. Авто-бот его добавляет — то есть бот будет постить **публично сам**.

## 🛡️ Авто-гейт безопасности (вместо ручного ревью)

Авто-постинг для **детского** центра без ревью — реальный риск (вспомни инвариант
C.4: подпись НИКОГДА не описывает конкретного ребёнка). Чтобы остаться **без ручной
работы, но безопасно**, ставим **автоматический** guardrail перед публикацией:

- подпись всегда генерится через уже существующий child-safe `CAPTION_SYSTEM`;
- перед публикацией Claude **сам себя проверяет**: подпись/выбор фото против инварианта
  детской безопасности и бренд-тона; не прошло → регенерация или пропуск, **не публикуем**;
- это автоматический фильтр, а не ручной шаг — правило «без ручного» соблюдено,
  бренд и дети защищены.

## Что нужно для запуска (после подключения Metricool)

1. Metricool подключён в claude.ai (OAuth) — проверю инструменты со своей стороны.
2. Перенести `composeBrandedStory()` из прототипа в `agents/content-bot/image.js` (новая
   функция рядом с существующими, квадратный поток не трогаем).
3. Собрать оркестратор цикла (research → plan → create → safety → schedule) как PM2-агент.
4. Включить авто-публикацию (осознанно снять «draft-only» границу) с авто-гейтом.
5. Прогнать 1 полный цикл на 1 посте + 1 сторис, проверить публикацию и метрики.
